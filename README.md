# Ink & Quill Chess — 기획 패키지

톰 리들의 일기장(riddle) 감성의 수채화 잉크 체스 게임 기획 + Codex 지시 패키지.

| 파일 | 내용 | 누가 읽나 |
|---|---|---|
| `AGENTS.md` | 스택·폴더 구조·코드 규칙·완료 기준 | Codex (자동으로 읽음) |
| `docs/01_기획서.md` | 컨셉, 아트 방향, 이동/불법이동/잡기 연출, 컷신 시스템, 화면, 사운드, 마일스톤 | 사람 + Codex |
| `docs/02_에셋_목록.md` | 이미지·VFX·폰트·사운드 규격과 이미지 생성 프롬프트 | 아트 작업하는 사람 |
| `docs/03_Codex_단계별_프롬프트.md` | Phase 0~6 그대로 붙여넣는 지시문 | Codex에 붙여넣기 |
| `docs/04_수정_프롬프트_v2.md` | **v2 방향 수정**: 정통 체스 말, 잉크 렌더링, 결투 안무 (Phase 2~3 대체) | Codex에 붙여넣기 |

## 바로 실행 (v3 프로토타입)
```
npm install
npm run dev
```
브라우저에서 `http://localhost:5179`(launch 설정 기준) 또는 Vite가 알려 주는 주소를 엽니다. 오른쪽 패널의 **결투 미리보기**로 6종 공격을 아무 말 조합에나 바로 재생해 볼 수 있습니다.

## 갤럭시 탭·폰에서 쓰기
**주소: https://xodid9977.github.io/ink-chess/**

1. 태블릿·폰의 Chrome(또는 삼성 인터넷)에서 위 주소 열기
2. 메뉴(⋮) → **홈 화면에 추가** (또는 "앱 설치") → 홈 화면의 잉크 체스 아이콘으로 실행
3. 한 번 열고 나면 인터넷 없이도 실행됨 (글꼴·그림 모두 기기에 저장)

수정한 뒤 다시 올리기: `npm run deploy` → 1~2분 뒤 반영, 태블릿 앱은 다음 실행 때 자동 업데이트

## 조작
- 시작 화면: 빈 일기장에 아무 글씨나 쓰면 시작 → `1`(혼자, 컴퓨터가 흑) 또는 `2`(둘이서) 쓰기 (또는 아래 글자를 눌러도 됨)
- 대국: 말을 눌러 고르고 갈 칸을 누르기 (끌어서 놓아도 됨). 오른쪽 일기장이 판의 상황을 잉크로 써 줌
- 아래 메뉴: 새 게임 · 뒤로 · 판 뒤집기 · 결투 연출 · 소리
- 결투 중 화면을 누르면 건너뜀
- 인터넷·유료 기능 없이 기기 안에서 모두 동작

## 시작 순서 (Codex로 이어서 만들 때)
1. 새 폴더(git 저장소)에 이 파일들을 그대로 복사
2. Codex에서 그 폴더를 열고 `03_Codex_단계별_프롬프트.md`의 **Phase 0**부터 하나씩 붙여넣기
3. 동시에 `02_에셋_목록.md` 9번 순서대로 아트 생성 → `public/assets/`에 넣기
4. Phase 5에서 실제 에셋으로 교체
