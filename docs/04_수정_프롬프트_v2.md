# 수정 지시문 v2 — 정통 체스 말 · 진짜 잉크 질감 · 결투 안무

> 이 문서는 1차 결과물을 본 뒤의 **방향 수정본**입니다. `03_Codex_단계별_프롬프트.md`의 Phase 2~3을 대체합니다.
> 피드백 세 가지:
> 1. 캐릭터형(치비) 말이 거부감 → **실제 체스 말(스탠턴형) 모양 그대로**
> 2. 잉크 질감이 아니라 평범한 게임처럼 보임 → **펜과 잉크로 종이에 그린 그림처럼**
> 3. 싸움이 "앞으로 가서 뚝딱" → **동작 하나하나를 박자 단위로 연출**

---

## 왜 "평범한 게임처럼" 보였나 (원인 진단)

Codex에게 "수채화 느낌으로"라고만 하면 거의 항상 이렇게 만듭니다.

| Codex가 보통 하는 것 | 그래서 생기는 느낌 | 이번에 바꿀 것 |
|---|---|---|
| 단색으로 채운 도형 + 일정한 두께의 외곽선 | 벡터 게임 UI | 두께가 불규칙하고 끊기는 **펜 선** + 얼룩진 **물감 채색** |
| 말을 종이 **위에 덮어서** 그림 (normal 블렌드) | 스티커를 붙인 느낌 | 잉크를 **곱하기(multiply)** 로 → 종이 결이 잉크 밑으로 비침 |
| 매 프레임 부드럽게 움직이는 필터 | 물결 셰이더 느낌 | 선이 **초당 10~12번 끊어서** 바뀌는 "보일링" → 손으로 그린 애니메이션 |
| 음영 = 그라디언트 | 디지털 페인팅 | 음영 = **빗금(해칭)** 과 교차 빗금 → 펜화 |
| 이펙트 = 파티클 원/별 | 모바일 게임 | 이펙트 = **깃펜이 실시간으로 그리는 획** + 종이에 스며드는 얼룩 |
| 움직임 = 직선 tween | "뚝딱" | 예비 동작 → 동작 → 정지(히트스톱) → 여운 |

**한 줄 원칙:** *"화면에 있는 모든 것은 누군가 지금 이 종이에 펜과 잉크로 그리고 있는 것이다."*

3. 각 프롬프트 끝의 **"검수 체크리스트"**를 직접 보고, 안 된 항목만 번호로 다시 지시하세요.

### 레퍼런스 이미지 준비 (사람이 할 일, 10분)
Codex는 저장소 안의 이미지를 볼 수 있습니다. 말로 "잉크 느낌"이라고 하는 것보다 그림 한 장이 훨씬 강력합니다.
- `docs/ref/` 폴더를 만들고 **"이런 느낌"** 이미지를 3~5장 넣으세요.
  - 예: 펜화로 그린 체스 말 일러스트, 수채화 펜 드로잉, 오래된 일기장 스케치
  - 이미지 생성 AI로 만든다면: `pen and ink drawing of a Staunton chess pawn and knight on aged paper, cross-hatching, loose watercolor wash, iron gall ink, sketchbook page`
- **가장 효과 좋은 방법:** 붓펜이나 만년필로 종이에 **획 20개, 얼룩 10개, 빗금 몇 줄**을 그려서 스마트폰으로 위에서 찍으세요. → `public/assets/ink/scan_*.jpg`. 진짜 잉크 스캔이 들어가면 디지털 느낌이 확 사라집니다.
- 종이 텍스처: [ambientCG](https://ambientcg.com) (CC0)에서 "Paper" 검색 → `public/assets/bg/paper_scan.jpg`

## 프롬프트 A — 방향 전환 & 정리
```
방향이 바뀌었어. 먼저 docs/04_수정_프롬프트_v2.md 전체와 docs/ref/ 안의 이미지를 확인해 줘.

변경 사항:
1. 캐릭터형(치비) 말 이미지는 모두 사용 중지. public/assets/pieces/ 와 cutscene/ 캐릭터 이미지는
   public/assets/_deprecated/ 로 옮기고 manifest에서 참조를 끊어.
2. 말은 실제 체스 말(스탠턴 형태) 모양을 그대로 쓴다. 팔다리·얼굴·무기 없음.
3. 진영 구분은 청색/적색이 아니라 전통적인 백/흑으로 바꾼다:
   - 백: 펜 선 위주 + 아주 옅은 물감, 종이 색이 대부분 남아 있음
   - 흑: 진한 먹 물감으로 칠하고, 빛 받는 쪽만 종이 색을 남김(하이라이트)
   금색(#C9962E)은 이동 가능 표시·마법 효과에만 쓰는 포인트 색.
4. 체스 규칙·입력·이벤트·컷신 director 구조는 그대로 유지. 렌더링과 연출만 다시 만든다.
5. 작업 시작 전에, 지금 화면을 Playwright로 캡처해서 screenshots/before/ 에 저장하고
   위 '원인 진단' 표 기준으로 현재 문제점을 5줄로 요약해 줘. 코드 수정은 그다음.
```

## 프롬프트 B — 스탠턴 체스 말 만들기
```
render/pieces/ 아래에 실제 체스 말(스탠턴 형태)을 코드로 만들어 줘. 이미지 파일 없이도 동작해야 해.

1) 회전체 프로필 방식
   폰·비숍·룩·퀸·킹은 좌우 대칭인 회전체야. config/pieceProfiles.ts 에
   "높이 y(0~1) → 반지름 r" 점 목록(반쪽 윤곽선)을 정의하고, 이걸 좌우로 뒤집어 붙여서 실루엣을 만든다.
   높이 비율 (킹 = 1.0):
   - 킹 1.00: 넓은 받침 → 오목한 허리 → 칼라(고리) 2단 → 볼록한 몸통 → 왕관 → 맨 위 십자가
   - 퀸 0.92: 킹과 비슷한 몸통 + 톱니 모양 관(작은 공 8개) + 맨 위 작은 공
   - 비숍 0.78: 받침 → 가는 기둥 → 칼라 → 달걀형 주교관 + 대각선으로 파인 홈 + 맨 위 작은 공
   - 나이트 0.72: 받침 + 말 머리 옆모습 (회전체가 아니므로 SVG path로 직접 그림:
     갈기, 귀, 콧등, 입, 목의 굴곡이 보이게. 왼쪽을 바라봄)
   - 룩 0.62: 넓은 받침 → 굵은 원통 몸통 → 위쪽으로 살짝 넓어짐 → 성가퀴(톱니 4개 보이게)
   - 폰 0.52: 넓은 받침 → 원뿔형 몸통 → 칼라 → 공 모양 머리
   칸 대비 크기: 킹 높이 = 칸의 0.92, 받침 폭 = 칸의 0.55 이하.
   64px 칸에서도 6종이 한눈에 구분되는지 확인할 것.

2) 음영용 법선 정보
   회전체라서 각 높이에서 반지름을 알 수 있으니, 픽셀마다 nx = (x - 중심) / r 로
   원통처럼 음영을 계산할 수 있다. 빛은 왼쪽 위에서. 이 값을 "음영 맵" 텍스처로 생성해
   프롬프트 C의 셰이더에 넘긴다. (나이트는 path 내부 거리 기반으로 근사)

3) 결과물: 말 1개 = { silhouette(알파 마스크), shading(음영 맵), outlinePath(펜 선용 경로) }
   를 RenderTexture로 미리 구워 둔다(게임 시작 시 1회).

4) 나중에 이미지 생성 AI로 만든 잉크 말 이미지(public/assets/pieces/ink_{w|b}_{p|n|b|r|q|k}.png)가
   있으면 그걸 쓰고, 없으면 이 코드 생성 말을 쓰도록 manifest에 폴백 처리.

검수 체크리스트:
□ 진짜 체스 세트처럼 보인다 (치비·얼굴 없음)
□ 64px에서 6종 구분 가능
□ 비숍 홈, 퀸 관의 공, 룩 성가퀴, 킹 십자가가 보인다
□ 나이트가 어색한 말 머리가 아니다 (갈기·귀·입이 있다)
```

## 프롬프트 C — 잉크 렌더링 파이프라인 ★가장 중요
```
fx/ink/ 아래에 PixiJS v8 커스텀 Filter(GLSL)로 '종이에 펜과 잉크로 그린 그림' 렌더링을 만들어 줘.
모든 말·이펙트·컷신이 이 파이프라인을 거친다. 수치는 config/ink.ts 에 모은다.

[레이어 1] 종이
- 바탕 #EFE3C8. paper_scan.jpg 가 있으면 그것을, 없으면 fbm 노이즈 3옥타브로 섬유결 생성.
- 큰 얼룩(커피 자국) 2~3개, 가장자리 비네팅 15%.
- 종이 결 텍스처를 '높이'로 써서 아래 잉크 레이어가 결을 따라 진하고 옅어지게 할 것(입자감).

[레이어 2] 물감 칠 (wash) — 말 내부
- 실루엣 안을 칠하되 균일하게 칠하지 말 것:
  a. 저주파 노이즈로 농도 얼룩 (농도 55~90% 사이에서 흔들림)
  b. 가장자리 진해짐(edge darkening): 알파를 블러한 값과 원래 알파의 차이로 테두리를 구해서
     테두리 2~4px를 20~35% 더 진하게 → 물감이 마르며 가장자리에 고이는 수채화 특징
  c. 입자(granulation): 종이 결 높이가 낮은 곳에 물감이 더 고이게
  d. 칠이 선에서 1~2px 어긋남(misregistration) + 가끔 선 밖으로 살짝 번짐
  e. 빛 받는 쪽(음영 맵 밝은 곳)은 칠하지 않고 종이 색을 남김
- 백 진영: 농도 계수 0.15 (거의 종이), 흑 진영: 0.85
- 블렌드는 반드시 multiply. 종이 결이 칠 밑으로 비쳐야 한다.

[레이어 3] 해칭 (펜 빗금 음영)
- 음영 맵이 어두운 쪽(오른쪽 아래)에 45° 빗금. 더 어두우면 -45° 교차 빗금 추가.
- 선 간격 3~4px, 선 두께와 위치를 노이즈로 흔들어서 손으로 그은 느낌. 빗금 끝은 실루엣 경계에서 살짝 넘치거나 모자라게.
- ink 스캔 텍스처(scan_*.jpg)가 있으면 빗금에 그 질감을 곱한다.

[레이어 4] 펜 외곽선
- outlinePath를 따라 선을 그리되:
  - 두께 0.6~1.8배로 변화 (곡선 바깥쪽·아래쪽은 두껍게, 위쪽은 가늘게 — 펜 압력)
  - 길이 방향으로 가끔(5~8%) 끊김, 획 시작/끝은 가늘게 빠짐
  - 선 색 #2A1E16 (iron gall), multiply
  - 마른 붓 느낌: 선 내부에 고주파 노이즈로 미세한 빈틈

[레이어 5] 보일링 (손그림 애니메이션의 핵심)
- 위 2~4 레이어의 노이즈 시드를 매 프레임 바꾸지 말고, 초당 10회(100ms마다)만 바꾼다.
  변위는 1~1.5px로 아주 작게. 말이 가만히 있어도 '살아 있는 펜 선'처럼 미세하게 떨려야 함.
- 부드럽게 보간하면 안 된다(물결 셰이더처럼 보임). 반드시 계단식.
- 시드 3개를 순환해도 충분.

[레이어 6] 화면 전체 후처리
- 톤: 채도 70%로 낮추고 따뜻한 세피아 쪽으로 살짝.
- (옵션, 설정에서 '전자잉크 모드') riddle의 전자잉크 화면 느낌:
  16단계로 명암 양자화 + 블루노이즈 디더링, 이전 프레임 잔상 6% 섞기(고스팅),
  컷신 전환 시 화면 전체가 0.06초 반전 깜빡(전자잉크 새로고침 플래시).

[잉크로 그려지는 등장 연출]
- 게임 시작 시 말들이 "그려지며" 등장:
  ① 외곽선이 획 단위로 그려짐(경로 dash 애니메이션, 말당 400ms, 아래→위)
  ② 물감이 받침에서부터 위로 번지며 차오름(노이즈 임계값 마스크, 300ms)
  ③ 빗금이 마지막에 슥슥 그어짐(150ms)
  말마다 40ms 시차, 백 → 흑 순서.

[성능]
- 말은 정지 상태일 때 보일링 3프레임을 RenderTexture로 미리 구워 순환 재생 → 셰이더 매 프레임 계산 X.
- 움직이는 동안만 실시간 셰이더. 60fps 목표, 저사양이면 해칭 OFF.

[디버그]
- ?debug=ink 로 레이어별 ON/OFF 토글 패널. 레이어 하나씩 끄며 효과 확인 가능하게.

검수 체크리스트:
□ 말을 확대했을 때 선 두께가 불규칙하고 끊긴 곳이 있다
□ 흑 말 안의 칠이 얼룩덜룩하고 테두리가 더 진하다
□ 종이 결이 잉크 밑으로 비친다 (스티커처럼 떠 보이지 않는다)
□ 그림자 쪽에 빗금이 있다
□ 가만히 있어도 선이 미세하게 '끊어서' 떨린다 (부드러운 물결이 아님)
□ 게임 시작 시 말이 펜으로 그려지며 나타난다
□ 레이어 디버그 패널이 동작한다
```

## 프롬프트 D — 이동 모션 다듬기 (딱딱한 말이 '연기'하는 법)
```
말은 팔다리가 없는 단단한 물체야. 그래서 움직임은 아래 4가지 동작의 조합으로만 표현한다.
이 규칙을 config/acting.ts 에 정리하고 모든 모션에 적용해 줘.

[딱딱한 말의 연기 규칙]
1. 기울기(tilt): 회전 중심은 말의 중심이 아니라 '받침의 한쪽 모서리'. 그래야 무게감 있게 까딱인다.
2. 깡충(hop): 짧게 떴다 내려앉음. 착지 순간 scaleY 0.96 → 1.02 → 1.0 (찌그러짐은 최대 4%까지만. 나무/돌이니까).
3. 미끄러짐(slide): 바닥을 밀고 감. 멈출 때 진행 방향으로 3~5° 기울었다가 되돌아옴(관성).
4. 떠오름(levitate): 비숍/마법 전용. 위아래로 천천히 흔들림.
모든 동작은: 예비 동작(반대 방향으로 10~20%) → 본동작 → 살짝 지나침(overshoot) → 진동하며 정착.
직선 linear 이징 금지. 착지에는 반드시 잉크 얼룩(종이에 스며들어 600ms 후 옅게 남음).

[말별 이동] (기존 config/pieces.ts 수정)
- 폰: 뒤로 4° 까딱(80ms) → 작은 깡충 1회로 전진(260ms, power2.out) → 착지 찌그러짐
- 나이트: 뒷모서리 기준 뒤로 15° 들림(120ms) → 포물선 점프(높이 0.9칸, 420ms), 공중에서 앞으로 숙임
  → 앞부터 착지, 반동 2회. 지나간 공중 궤적에 마른 붓 자국이 남았다 사라짐
- 비숍: 0.1칸 떠오름 → 대각선 활주(340ms, sine.inOut), 받침 아래 옅은 그림자가 따라감 → 내려앉음
- 룩: 미끄러짐(380ms, power3.inOut). 바닥에 마른 붓으로 긁힌 자국 2줄. 정지 시 화면 흔들림 3px 100ms
```

```
잡기 컷신을 아래 안무표대로 다시 만들어 줘. 지금은 '앞으로 가서 부딪힘' 한 가지 동작뿐이라 조잡해 보여.
모든 시간(ms)·각도·거리는 config/choreo.ts 에 넣고, 공격 하나 구현할 때마다 ?debug=1 패널에서 확인한 뒤 다음으로 넘어가.

========== 공통 원칙 ==========
P1. 컷신의 핵심 컨셉: "일기장의 보이지 않는 깃펜이 무기와 효과를 실시간으로 그려 준다."
    말에게 팔이 없으니, 창·랜스·검·마법진은 깃펜이 획 단위로 그려서(stroke 애니메이션) 말 옆에 붙인다.
    그려진 무기도 프롬프트 C의 잉크 파이프라인을 거친다(불규칙한 선, 보일링).
P2. 모든 공격은 4박자: 예비 동작(anticipation) → 동작(action) → 임팩트(히트스톱) → 여운(follow-through).
    예비 동작이 길고 동작이 짧을수록 강해 보인다. 동작 구간은 60~120ms로 아주 빠르게.
P3. 히트스톱: 임팩트 순간 모든 움직임을 멈춘다(60~160ms). 단, 보일링(선 떨림)은 계속 돈다 → 정지 화면이 아니라 '숨 멈춘' 느낌.
P4. 모션 블러 대신 '잉크 잔상': 빠른 동작 뒤에 말 실루엣 잔상 3개(물감만, 알파 .35/.2/.1) + 진행 방향으로 늘어진 마른 붓 자국.
P5. 카메라: 줌·이동은 power3.inOut. 흔들림은 랜덤 지터가 아니라 '감쇠하는 노이즈'(진폭이 지수적으로 줄어듦).
    더치 앵글(카메라 기울기)은 킹 공격에만.
P6. 잉크 방울은 원형 파티클 금지. 날아가는 동안은 길쭉한 획, 종이에 떨어지면 번지는 얼룩(bloom)으로 바뀐다.
P7. 전투가 끝나도 그 칸에 옅은 얼룩(알파 0.12)이 게임 끝까지 남는다. 일기장에 전투가 기록되는 느낌. 칸당 최대 3겹.
P8. 소리는 임팩트 프레임에 정확히 맞춘다.

========== 공통 컷신 뼈대 ==========
[0] 접근 (0~220ms): 공격자가 피해자 칸 0.35칸 앞까지 이동 후 정지. 히트스톱 80ms.
[1] 전환 (220~520ms): 카메라가 두 말의 중간 지점으로 2.6배 줌(power3.inOut).
    동시에 주변 보드가 물에 씻기듯 흐려지고 옅어짐(블러 + 채도↓ + 종이 색으로 덮임). 종이 넘기는 소리.
    전자잉크 모드면 이 순간 반전 플래시 60ms.
[2] 대치 (520~900ms): 두 말이 화면 1/3, 2/3 위치에 크게. 피해자는 뒤로 3° 움찔.
    공격자는 앞뒤로 2° 까딱 2회(숨 고르기). 바닥에 두 말의 그림자가 잉크 얼룩으로.
[3] 공격 (공격 종류별 안무, 아래)
[4] 리액션 (공격 종류가 결정, 아래)
[5] 여파 (300ms): 튄 잉크가 종이에 스며들며 옅어짐. 공격자가 자세를 바로 하며 정착.
[6] 복귀 (350ms): 씻겨 나갔던 보드가 다시 그려지며 돌아오고 카메라 줌아웃.
    공격자는 정확히 목표 칸에 착지(얼룩). 잡힌 말은 사이드 묘지에 깃펜으로 작게 다시 그려짐.

========== [3] 공격 안무 ==========

■ 폰 — 찌르기 (Pierce)  "떨면서도 용감한 신병"
 1. 무기 그리기 (180ms): 깃펜이 폰 머리 높이에서 앞쪽으로 창대를 한 획에 긋는다(뒤→앞).
    이어서 창날(뾰족한 삼각형)을 두 획으로. 창끝에서 잉크 한 방울이 맺혀 떨어진다.
 2. 예비 (220ms): 뒷모서리 기준으로 뒤로 12° 기울며 0.1칸 물러남(power2.out).
    60ms 동안 ±1° 미세하게 떨림(긴장).
 3. 동작 (90ms): 앞으로 튀어나가며 -18°로 숙임(power4.in). 잉크 잔상 + 마른 붓 자국.
 4. 임팩트: 창끝이 피해자 중앙에 닿는 순간 히트스톱 100ms.
    첫 1프레임 임팩트 지점이 종이 색으로 하얗게 → 다음 프레임 잉크 폭발.
    잉크 방울 20~24개가 '찔린 반대 방향'으로 부채꼴 분사, 중력 받아 떨어져 얼룩이 됨.
    카메라 흔들림 6px, 250ms 감쇠. 소리: 짧은 찌르기 + 잉크 튀는 소리.
 5. 여운 (300ms): 반동으로 0.2칸 뒤로, 받침 위에서 3번 까딱이며 정착(진폭 점점 작게).
    창은 끝에서부터 잉크가 말라 옅어지며 사라짐(색이 진해졌다가 연한 세피아로).
 → 리액션: 꿰뚫림

■ 나이트 — 돌진 (Charge)  "마상 창 시합"
 1. 무기 그리기 (200ms): 깃펜이 말 머리 앞으로 길고 끝이 가늘어지는 랜스를 긋는다. 뒤쪽에 속도선 3줄.
 2. 예비 (250ms): 뒷모서리 기준 20° 뒤로 들림 + 0.3칸 떠오름(back.out) — 앞발 드는 말.
    받침 아래 마른 붓 흙먼지 2~3번.
 3. 동작 (260ms): 포물선 도약으로 피해자에게, 공중에서 앞으로 숙이며 가속(power2.in).
 4. 임팩트: 랜스/말 머리가 피해자 윗부분에 충돌. 히트스톱 120ms.
    충격파: 불규칙한 두께의 잉크 고리가 깃펜으로 그려지며 퍼짐(350ms).
    카메라 '줌 펀치': 1.08배 순간 확대 후 복귀(150ms).
 5. 여운 (350ms): 나이트는 피해자 너머에 착지해 0.3칸 미끄러짐(바닥 긁힌 자국 2줄),
    좌우 반전으로 뒤돌아 피해자 쪽을 봄.
 → 리액션: 날아감

■ 비숍 — 잉크 마법 (Ink Magic)  "주문을 적는 사제" (riddle 오마주)
 1. 준비 (400ms): 비숍이 0.15칸 떠오르며 천천히 위아래로 흔들림.
    주교관의 홈에 금빛(#C9962E)이 스민다.
    발밑 종이에 깃펜이 마법진을 '쓴다': 원 하나 + 문양 6획을 한 획씩(riddle의 글씨가 써지는 연출과 같은 방식).
 2. 집중 (300ms): 마법진에서 잉크가 물방울처럼 솟아 비숍 머리 위로 나선을 그리며 모여 소용돌이가 됨.
 3. 동작 (150ms): 소용돌이에서 잉크 리본(끝이 가늘어지는 곡선, 가장자리가 진한 수채 띠)이 대각선으로 뻗어 피해자에게.
 4. 임팩트: 리본이 피해자를 두 바퀴 휘감음(200ms). 히트스톱 80ms. 물방울 떨어지는 소리 + 낮은 울림.
 5. 여운: 마법진이 바래며 사라지고 비숍이 내려앉음.
 → 리액션: 녹아내림

■ 룩 — 분쇄 (Crush)  "무너지는 성벽"
 1. 예비 (400ms): 룩이 그대로 수직으로 0.8칸 천천히 떠오름(sine.inOut).
    받침에서 작은 돌 부스러기(짧은 펜 획)가 떨어짐. 바닥 그림자가 피해자 위로 이동하며 작고 진해짐(조준).
 2. 정지 (120ms): 꼭대기에서 ±2° 흔들리며 멈춤. 피해자가 위를 올려다보듯 뒤로 5° 기울어짐.
 3. 동작 (80ms): 수직 낙하(expo.in).
 4. 임팩트: 히트스톱 140ms. 화면 흔들림 10px, 400ms 감쇠.
    바닥에 먹 폭발 얼룩 + 깃펜이 갈라진 금을 번개 모양으로 방사형으로 그음(200ms).
    종이가 움푹 꺼지는 듯한 변위 펄스 1회. 소리: 묵직한 돌 충돌 + 낮은 쿵.
 5. 여운 (300ms): 룩이 반동으로 0.05칸 튀었다 내려앉음. 먼지 잉크가 천천히 가라앉음.
 → 리액션: 산산조각

■ 퀸 — 연속 베기 (Slash Combo)  "우아한 칼춤"
 1. 예비 (350ms): 제자리 회전 2바퀴(scaleX를 cos로 흔들어 입체 회전처럼, 점점 빨라짐).
    회전하는 동안 주변에 잉크 리본이 감기며 따라 돎.
 2. 순간이동 (120ms): 퀸이 잉크 튀김으로 흩어졌다가 피해자 바로 옆에서 다시 모여 나타남.
 3. 3연격: 깃펜이 피해자를 가로질러 곡선 붓획을 긋는다.
    1타 -30°, 2타 +25°, 3타 수평. 각 획 70ms, 사이 간격 90ms.
    1·2타: 히트스톱 50ms, 작은 잉크 분사, 피해자에 머리카락처럼 가는 베인 선이 남음(살짝 번짐).
    3타: 가장 굵은 획, 히트스톱 120ms, 큰 분사, 카메라 흔들림 5px.
    소리: 칼 3번, 마지막이 가장 길게.
 4. 여운 (250ms): 퀸은 피해자를 등지고 멈춰 선 자세(정적 150ms). 이 '등 돌린 정적'이 이 연출의 포인트.
 → 리액션: 두 동강 (3타 선을 따라 갈라짐)

■ 킹 — 일도양단 (Cleave)  "위엄 있는 한 칼"
 1. 무기 그리기 (300ms): 킹 머리 위에 깃펜이 큰 대검을 칼끝→손잡이 순으로 그린다. 검이 공중에 떠 있음.

 3. 동작 (70ms): 검이 위에서 아래로 내려침. 지나간 자리에 아주 넓은 마른 붓 호(arc) 획이 남음.

    피해자 중앙에 수직선 하나.
 5. 여운 (300ms): 검이 잉크로 녹아 흘러내리며 사라짐. 카메라 기울기 원위치.
 → 리액션: 두 동강 (수직)

========== [4] 리액션 ==========

■ 꿰뚫림 (pierced)
 1. 피해자가 0.1칸 뒤로 밀림.
 2. 찔린 지점에서 진한 먹이 물감 위로 번져 퍼짐(수채화 bloom, 500ms) — 칠 위에 얼룩이 번지는 모양.
 3. 뒷모서리 기준 90° 뒤로 넘어짐(400ms, bounce.out, 작은 반동 2회).
 4. 넘어진 뒤 아래쪽부터 액체가 되어 종이에 스며듦 → 웅덩이 얼룩 → 마르며 옅어짐(600ms).

■ 날아감 (knockback)
 1. 35° 위쪽으로 튕겨 나가며 540° 회전, 카메라 쪽으로 살짝 커지며 화면 밖으로(450ms).
 2. 궤적에 잉크 방울이 뚝뚝 떨어져 얼룩.
 3. 화면 밖에서 '툭' 소리 후 200ms 뒤 화면 구석에 작은 잉크 튀김(어딘가에 떨어졌다는 암시) — 웃음 포인트.

■ 녹아내림 (dissolve)
 1. 휘감긴 리본이 조여지며 피해자 펜 선이 아래로 흘러내리기 시작(세로 변위가 아래로 갈수록 커짐, 젖은 잉크 흐르듯) 600ms.
 2. 칠한 물감이 물에 씻겨 옅어짐(채도·농도↓). 흘러내린 잉크가 바닥에 고임.
 3. 마지막엔 워터마크처럼 희미한 실루엣만 남았다 사라짐(400ms).

■ 산산조각 (shatter)
 1. 피해자에 금이 깃펜으로 그어짐(100ms).
 2. 미리 계산한 보로노이 조각 6~10개로 깨져 회전하며 사방으로 날아감(중력 적용).
    조각마다 짧은 잉크 꼬리. 떨어진 조각은 잉크를 쏟으며 얼룩이 됨.
 3. 받침만 잠깐 남았다가 부스러져 가라앉음(300ms).

■ 두 동강 (split)  ← "썰어버리는" 연출
 1. 베인 선이 2px 종이색 틈으로 드러남.
 2. 150ms 동안 아무 일도 안 일어남 — '베인 걸 깨닫는 순간'. 이 정적이 핵심, 줄이지 말 것.
 3. 위쪽 조각이 베인 선 방향으로 가속하며 미끄러져 떨어짐(살짝 회전). 아래쪽은 제자리에서 한 번 휘청.
 4. 잘린 단면 양쪽 테두리에서 진한 잉크가 번져 나오고 방울이 떨어짐(피 대신 잉크).
 5. 두 조각 모두 쓰러진 뒤 종이에 스며들어 얼룩으로(500ms).

========== 특수 조합 (기존 specials 갱신) ==========
- 폰×퀸: 폰의 예비 동작 떨림을 3배 길게(눈 질끈 감는 느낌), 퀸은 대치 때 여유롭게 까딱 → 찔리고 놀라 뒤로 크게 휘청 후 쓰러짐
- 폰×폰: 두 폰이 서로 창을 그려 창끼리 부딪혀 X자로 버팀(밀당 400ms, 둘 다 떨림) → 공격자가 이김
- 나이트×나이트: 화면 양끝에서 동시에 달려와 교차(서로 랜스), 교차 후 피해자만 늦게 쓰러짐(0.3초 지연)
- 퀸×퀸: 서로 3합 칼 교차(획이 X자로 3번), 마지막에 공격자만 서 있음
- 앙파상: 피해자가 앞을 보고 있는 사이 옆에서 폰이 '쏙' 찌름 → 피해자가 천천히 옆을 돌아봄(좌우 반전) → 쓰러짐
```
