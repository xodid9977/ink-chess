# 에셋 & 리소스 목록

> Codex는 이미지를 만들지 못합니다. **아트는 이미지 생성 AI(ChatGPT 이미지, Midjourney, Nano Banana 등)로 따로 만들고**, 아래 경로·이름 규격대로 `public/assets/`에 넣으면 코드가 자동으로 교체합니다. 그 전까지는 플레이스홀더로 돌아갑니다.

## 0. 공통 규격
- 형식: PNG(투명 배경), 사운드는 OGG + MP3 둘 다
- 파일명: 소문자_스네이크케이스, 진영 접두어 `w_`(청색 잉크) / `b_`(진홍 잉크)
- 보드용 말: **512×512**, 말 하단 중앙이 발 위치
- 컷신 일러스트: **1536×1536**, 캐릭터가 화면 오른쪽을 바라보게 (코드에서 좌우 반전)
- 배경 제거: 생성 후 remove.bg / Photoshop 등으로 투명 처리, 가장자리 번짐은 살리기

## 1. 스타일 고정 프롬프트 (모든 이미지 앞에 붙이기)
일관성이 가장 중요합니다. 아래 문장을 **매번 그대로** 앞에 붙이고, 첫 결과물 중 마음에 드는 것을 레퍼런스 이미지로 계속 첨부하세요.

```
Hand-painted watercolor and ink illustration on aged parchment, loose wet-on-wet brush strokes,
soft bleeding edges, visible paper grain, iron-gall brown ink linework with uneven thickness,
storybook fantasy diary style, muted sepia palette with {ACCENT} ink as the only strong color,
no pixel art, no 3D render, no photorealism, plain background, centered, full body.
```
- 백 진영: `{ACCENT}` = `deep indigo blue (#2F4E7A)`
- 흑 진영: `{ACCENT}` = `crimson red (#7A1F2B)`

> ## ⚠️ v2 수정 — 3장·4장 대체
> 캐릭터형 말(3장)과 컷신 캐릭터 파츠(4장)는 **쓰지 않습니다.** 말은 Codex가 코드로 스탠턴 실루엣을 만들고 잉크 셰이더로 그립니다(`04_수정_프롬프트_v2.md` 프롬프트 B·C).
> 이미지로 대체하고 싶을 때만 아래 12장(`pieces/ink_{w|b}_{p|n|b|r|q|k}.png`, 512×512, 정면 옆모습)을 만드세요:
> ```
> Pen and ink drawing of a classic Staunton chess {PIECE}, side view, on aged parchment,
> iron gall ink linework with uneven pressure and broken lines, cross-hatching on the right side,
> {WASH}, loose watercolor edges, sketchbook illustration, no characters, no face, plain background
> ```
> - 백: `{WASH}` = `almost no paint, paper left white, only a faint grey wash in the shadows`
> - 흑: `{WASH}` = `filled with dense black-brown ink wash, darker pooled edges, highlight on the left left unpainted`
>
> **v2에서 가장 중요한 에셋은 그림이 아니라 진짜 잉크 스캔입니다:** 붓펜/만년필로 종이에 획 20개·얼룩 10개·빗금 몇 줄을 그려 위에서 찍은 사진 → `ink/scan_*.jpg`. 종이 스캔은 ambientCG(CC0) "Paper" → `bg/paper_scan.jpg`.

## 4. (v1, 폐기) 컷신 캐릭터 (컷아웃 파츠 방식)
각 말 × 진영(12세트)마다 **파츠를 분리해서** 생성/편집합니다. 한 장의 전신 일러스트를 만든 뒤 포토샵·Photopea(무료)에서 레이어를 잘라도 됩니다.

```
cutscene/{w|b}_{p|n|b|r|q|k}/
  full.png          # 전신 1장 (1536×1536) — 대치 장면용
  head.png  body.png  arm_front.png  arm_back.png  weapon.png  legs.png
  broken_*.png      # 부서질 때 날아갈 조각 3~6개 (룩=돌 조각, 비숍=지팡이 등)
  rig.json          # 각 파츠의 pivot(회전축) 좌표
```
`rig.json` 예시:
```json
{ "head": { "x": 768, "y": 420 }, "arm_front": { "x": 860, "y": 640 }, "weapon": { "x": 900, "y": 700 } }
```
프롬프트 뒷부분 예: `dynamic battle pose of a young foot soldier lunging forward with a spear, side view facing right`

> 시간이 없으면 **full.png만** 만들어도 됩니다. 코드가 전신 한 장을 통째로 기울이고·자르고·녹이는 방식으로 대체합니다(퀄리티는 조금 낮음).

## 9. 제작 우선순위 (아트 작업 순서)
1. 스타일 테스트: 폰 1장(청/적) 만들어 보고 톤 확정 ← **여기서 오래 고민할 가치 있음**
2. 보드용 말 12장 + 타일 + 종이 배경 → 게임이 "그럴듯해 보이는" 최소 세트
3. VFX 5종 (잉크 스플래시·참격·충격파·소용돌이·폭발)
4. 컷신 full.png 12장
5. 컷신 파츠 분리 + 부서지는 조각
6. 사운드 → BGM
